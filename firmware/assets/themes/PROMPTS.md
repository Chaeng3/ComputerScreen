# 动漫主题素材

使用内置 ImageGen 生成，参考本目录的 `concept-board.png`（原文件名“动漫三景液晶主题概念板.png”）。参考图仅用于构图与氛围，不作为实际画面的一部分。三张原始 PNG 保存在本目录，固件使用 `tools/pack_themes.py` 转换的 RGB565 数据。

共同提示：独立的 4:3 全幅手绘动漫风景，无文字、数字、时钟、图标、设备、拼贴或边框。面向 320×240 小屏，地平线约 62% 高度，中央上半部留平静天空给白色时间，中央下部留平静水面给天气。细节集中在边缘与下角。

- `day.png`：夏日蓝天与湖泊、远山、边缘白云、绿色草地和黄色野花；远左下角小幅黑发少女坐看湖面；清爽蓝绿配色，中央较深蓝天空。
- `dusk.png`：紫粉色傍晚天空、边缘橙金云彩、右侧低位夕阳、远处紫山与海湾、底部两角红瓦小镇和花草、极右侧老式路灯；中央留平静紫色天空，不绘制参考图中的翻页时钟。
- `night.png`：深靛蓝星空、右上侧淡紫银河、极左侧小弯月、层叠蓝色山影、平静湖面和远处小镇灯光、底部野花、极右下角小幅黑发少女仰望夜空；中央留深色空间。

动画由固件实时生成：晴空轻微云层移动、黄昏水波与微光、星夜星光闪烁及偶尔掠过的流星。原始 PNG 无动画、无 UI 文字。
